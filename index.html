Full-Stack Architecture & Safety Framework

Commuto connects students and workplace commuters to cut daily travel expenses and highway congestion. The platform integrates end-to-end security, live telemetry, and community trust:

Women-Only Pooling Option

Dedicated safety filter enabling female commuters to search, match, and ride exclusively with verified women passengers and drivers.

1-Touch Emergency SOS Shield

Instant panic alert dispatch broadcasting live GPS coordinates and telemetry logs to emergency contacts and campus security.

Live GPS & WebSocket Chat

Interactive Leaflet maps for route visualization and Spring STOMP WebSockets for real-time driver coordinates and in-app ride coordination.

In-App Wallet & Razorpay

Digital wallet balance management with Razorpay payment checkout for transparent fuel-cost splitting with ₹0 commission fee.

Production Tech Stack & Standards:

Frontend: Next.js 16, React 19, TypeScript, Tailwind CSS v4, Vercel Edge • Backend: Spring Boot 3.4, Java 21, Spring Security 6 (JWT + Google OAuth), STOMP WebSockets • Database: PostgreSQL 16 with Flyway automated schema migrations.
