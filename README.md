## ⚡ Quick Start (Local Setup)

### Option 1: Using Node.js (Recommended)
Clone the repository and run the built-in development server:
```bash
# 1. Clone repository
git clone https://github.com/ananyajain327/Portfolio.git

# 2. Navigate to project root
cd Portfolio

# 3. Start local development server
npm start
# or: node serve.js
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

### Option 2: Direct Browser Launch
Simply double-click `index.html` or open it with any web browser (Chrome, Edge, Firefox, Safari). All typography and icon dependencies load seamlessly over HTTPS CDN.

## 🌐 Deploying to GitHub Pages

Deploy your portfolio live in under a minute with GitHub Pages:

1. Push your repository to GitHub:
   ```bash
   git add .
   git commit -m "Deploy latest portfolio"
   git push origin main
   ```
2. Navigate to your repository on GitHub:
   - Go to **Settings** > **Pages** (under the "Code and automation" sidebar).
   - Under **Build and deployment**:
     - **Source**: `Deploy from a branch`
     - **Branch**: `main`
     - **Folder**: `/ (root)`
   - Click **Save**.
3. In ~30 seconds, your site will be live at:
   ```
   https://ananyajain327.github.io/Portfolio/
   ```
